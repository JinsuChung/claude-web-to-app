이 과정을 마치면 **아이디어 하나를 기획서와 목업으로 정리하고, Claude Code로 웹앱을 만들어 인터넷에 공개하고, 데이터베이스와 AI를 붙인 뒤, 휴대폰 앱으로까지** 만들 수 있습니다. 코딩을 한 번도 해 본 적 없어도 괜찮습니다.

<Callout title="이 과정의 한 문장">
  코드를 외우는 대신, 무엇을 만들지 정하고 · 맡기고 · 확인하는 법을 배웁니다. 그것이 요즘 업계가 실제로 일하는 방식입니다.
</Callout>

## 누구를 위한 과정인가요

| 항목 | 내용 |
| --- | --- |
| 대상 | 코딩을 처음 배우는 누구나. 컴퓨터로 문서 작성과 인터넷 검색을 할 수 있으면 충분합니다 |
| 강의 | 코그니랩스 정진수 |
| 시간 | 한 회 2시간(중간 쉬는 시간 10분) × 15회 |
| 방식 | 매 회 개념 설명 → 요즘 업계 이야기 → 시연 → 따라 하는 실습 → 정리와 퀴즈 |
| 결과물 | 내가 기획한 &ldquo;우리 모임&rdquo; 서비스: 인터넷 주소로 열리는 웹앱 + 휴대폰에 설치되는 앱 |

### 왜 &ldquo;웹에서 앱까지&rdquo; 순서인가요

- **웹앱이 가장 빠릅니다.** 만들자마자 주소 하나로 누구에게나 보여 줄 수 있고, 고치면 바로 반영됩니다.
- **웹에서 만든 것이 앱의 재료가 됩니다.** 기획서, 목업, 데이터베이스, 로그인, AI 기능을 앱에서도 그대로 다시 씁니다.
- **앱은 마지막에 &ldquo;화면 하나 더&rdquo;가 됩니다.** 데이터는 웹과 앱이 함께 쓰고, 앱은 휴대폰에 맞는 화면을 하나 더 만드는 일이 됩니다.

### 왜 Claude와 Claude Code인가요

- **Claude(채팅)**는 생각을 정리하는 동료입니다. 아이디어를 인터뷰해 기획서로, 기획서를 클릭되는 목업 화면으로 만들어 줍니다.
- **Claude Code**는 내 컴퓨터에서 직접 일하는 동료입니다. 폴더를 열어 파일을 만들고, 프로그램을 실행해 확인하고, 에러를 고칩니다.
- 하나의 계정, 하나의 앱 안에서 **기획 문서와 코드 양쪽을 오갈 수** 있고, 두 일 모두에서 최상위 성능을 보여 줍니다. 1회에서 자세히 다룹니다.

1–3회는 **시작하기**, 4–6회는 **웹앱 만들기**, 7–9회는 **데이터와 로그인**, 10회는 **AI 기능**, 11–14회는 **앱으로**, 15회는 **마무리**입니다. 모든 회가 지난 회의 결과물 위에 쌓이는 이어지는 실습입니다. 한 회를 놓쳤다면 그 회 페이지만 보고도 따라올 수 있도록 단계마다 예상 결과와 &ldquo;막혔을 때&rdquo; 도움말을 넣어 두었습니다.
