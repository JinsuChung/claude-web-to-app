## 프롬프트 복사하기

모든 프롬프트 상자에는 **복사** 버튼이 있습니다. 누른 뒤 Claude Code 입력창에 붙여 넣으세요 (<Kbd keys="mod+v" />).

<PromptCard id="explain-like-beginner" />

- **주황색 글자**는 바꿔 쓸 수 있는 빈칸입니다. 그대로 복사하면 예시 값이 들어갑니다.
- **빈칸 채우기**를 누르면 입력란이 열립니다. 입력한 값은 이 브라우저에 저장돼 다음에도 남아 있어요.
- **왜 이렇게 쓰나요?**를 누르면 프롬프트를 이렇게 쓰는 이유와 아쉬운 예가 나옵니다.
- 별표(☆)를 누르면 [프롬프트 라이브러리](/prompts)의 즐겨찾기에 모입니다.

## 실습 단계 체크하기

실습은 단계별로 나뉘어 있습니다. 단계를 마치면 동그라미를 눌러 완료로 표시하세요. 회차 머리말과 왼쪽 사이드바에 진도가 쌓입니다.

<Callout type="info" title="진도는 기본적으로 이 브라우저에 저장돼요">
  아래의 **별명으로 참여**를 하면 다른 PC에서도 이어 할 수 있고 반 전체 현황에도 모입니다. 참여하지 않으면 이 브라우저에만 남고, 방문 기록·쿠키를 지우면 함께 지워집니다.
</Callout>

## 우리 반 현황에 참여하기

왼쪽 사이드바의 **별명으로 우리 반 현황에 참여하기**(또는 홈의 **별명으로 참여하기**)를 누르고 별명과 숫자 4자리 PIN을 정하면 됩니다.

- 참여한 뒤에는 실습 단계를 체크할 때마다 **자동으로** 반 전체 현황에 모여요. 따로 저장 버튼을 누를 필요가 없습니다.
- 홈의 **우리 반 진행 현황**에서 과정별로 몇 명이 완료했는지, 최근 누가 완료했는지 볼 수 있어요. 회차 머리말에도 "우리 반 n명 중 m명 완료"가 보입니다.
- 다른 PC나 휴대폰에서는 **같은 별명과 PIN**으로 참여하면 진도가 합쳐져 이어집니다.
- 별명을 숨기고 싶으면 사이드바의 내 이름을 눌러 **익명**으로 바꿀 수 있어요. **내 기록 지우기**도 그곳에 있습니다.

<Callout type="warn" title="PIN은 간단한 확인용이에요">
  다른 곳에서 쓰는 비밀번호나 실명·전화번호는 쓰지 마세요. 저장되는 것은 별명, 암호화한 PIN, 실습 체크 현황뿐이고 과제에 쓴 글은 저장되지 않습니다. PIN을 잊으면 새 별명으로 참여하면 됩니다.
</Callout>

## 막혔을 때

실습 단계마다 **막혔을 때** 상자가 있습니다. 증상을 누르면 해결 방법이 펼쳐집니다. 그래도 안 되면 에러 메시지를 그대로 복사해 Claude Code에 붙여 넣으세요.

## 발표 모드 (수업 중 함께 보기)

강사가 프로젝터에 띄울 때 쓰는 모드입니다. 수강생도 크게 보고 싶을 때 쓸 수 있어요.

| 키 | 동작 |
| --- | --- |
| <Kbd keys="P" /> 또는 상단 **발표 모드** | 켜기 / 끄기 |
| <Kbd keys="→" /> <Kbd keys="Space" /> | 다음 슬라이드 |
| <Kbd keys="←" /> | 이전 슬라이드 |
| <Kbd keys="T" /> | 실습 타이머 (3·5·10·15분) |
| <Kbd keys="Q" /> | 지금 페이지 QR 코드 — 휴대폰으로 같은 위치 열기 |
| <Kbd keys="esc" /> | 발표 모드 끝내기 |

발표 모드에서는 본문이 소제목 단위로 한 화면씩 나뉩니다.

## 검색

상단 검색창(<Kbd keys="mod+K" />)에서 회차 본문, 프롬프트, 용어를 찾을 수 있습니다.

## 인쇄

각 페이지 위쪽의 **인쇄 / PDF** 버튼을 누르면 사이드바와 버튼을 뺀 깔끔한 모양으로 인쇄됩니다. 실습 자료와 템플릿은 [자료실](/downloads)에 있어요.
